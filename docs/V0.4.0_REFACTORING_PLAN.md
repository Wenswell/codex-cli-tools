# v0.4.0 架构重构与精简方案 (Plan)

## 概述

随着工具链使用场景演进，本项目在 v0.4.0 中对功能面进行大幅度精简与聚焦：
1. **移除 Codex app-server daemon 交互**：`cx`、`cxx`、`cxxs` 回归直接运行本地官方 `codex` 的自然行为，去除 `--remote unix://`、`-C` 路径传参及 `local` 前缀修饰，移除 `ccs r`。
2. **移除余额/用量查询与状态服务**：去除所有 `/v1/usage` 轮询与展示，去除 `ccs s *`（状态服务/监控/WezTerm 接入）、`ccs usage *`（用量目标管理）、`ccs top` 命令行轮询以及 `ccs list --usage` 标志。
3. **移除价格、成本与模型查询系统**：去除 `ccs pricing *`（LiteLLM 价格表拉取与过滤）、`ccs cost *`（本地 SQLite/JSONL 成本聚合分析与局域网中心化 push/central 报表），去除 `ccs models *`（不再查询与显示 /v1/models）。
4. **清理依赖与文档**：移除 `asciichart`、`luxon` 等只用于上述特性的第三方依赖；更新 `README.md` 与文档索引；版本升级至 `0.4.0`。

---

## 详细改动设计

### 1. `cx` / `cxx` / `cxxs` 回归正常 Codex
- **`cx [ARGS...]`**：执行 `codex --search ARGS...`。
- **`cxx [ARGS...]`**：执行 `codex --search --dangerously-bypass-approvals-and-sandbox ARGS...`。
- **`cxxs [ARGS...]`**：执行 `codex --search --dangerously-bypass-approvals-and-sandbox resume ARGS...`。
- **保留 `run PROFILE [ARGS...]`**：单次指定 Profile 启动 Codex，通过环境变量及 `-c` 覆盖 provider 配置，无缝支持已安装的 `ccs proxy`。
- **移除**：
  - 不再解析 `local` 参数（默认即本地执行）。
  - 不再附加 `--remote unix:// -C $PWD`。
  - 移除 `ccs r` 子命令。

### 2. 移除 Usage 与状态服务
- **移除命令**：
  - `ccs top`
  - `ccs s *`（`line`, `agent`, `server`, `history`, `pause`, `resume`, `reset`, `wezterm`）
  - `ccs usage *`（`ccs usage`, `ccs usage add`, `ccs usage remove`）
  - `ccs list -u` / `ccs list --usage`
- **行为调整**：
  - `ccs` 无参数入口仅显示当前 Profile、API 端点、转换状态、配置文件路径，不再发起网络请求打印 `usage:` 行。
  - `ccs PROFILE` 和 `ccs toggle` 切换后不再打印 `usage:` 行。
  - 紧凑 footer 调整为：
    ```text
    commands:   version | PROFILE | toggle | list | init | sync | add | remove
    namespaces: proxy | config | --help
    ```

### 3. 移除 Pricing、Cost 与 Models
- **移除命令**：
  - `ccs pricing *`
  - `ccs cost *`
  - `ccs models *`
- **代码清理**：
  - 移除 `src/commands/ccs.ts` 中的 `printModels` 及相关 models 获取逻辑。
  - 删除 `src/lib/codex-usage.ts`（用于解析 SQLite 和 JSONL 统计 Session Token 的库）。
  - 精简 `src/lib/pricing.ts`（若 proxy 仅使用基本类型则保留最小子集）。

### 4. 依赖精简与版本提升
- 移除生产依赖：`asciichart`、`luxon`。
- 移除开发依赖：`@types/asciichart`、`@types/luxon`。
- `package.json` 版本升级为 `0.4.0`。

### 5. 文档体系清理
- 删除过时规格与计划：
  - `docs/CCS_COST_SPEC.md`
  - `docs/PASSTHROUGH_CAPACITY_RETRY_PLAN.md`
  - `docs/PROXY_CANCEL_ENHANCEMENT_PLAN.md`
- 更新 `docs/README.md` 与 `docs/ENGINEERING_PREFERENCES.md`。
- 重写根目录 `README.md` 中对应章节。

### 6. 测试维护
